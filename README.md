# WoW Forever 术士助手（zhCN 汉化增强版）

魔兽世界：无限（WoW Forever）可用的术士工具插件汉化增强包。基于 Dyre 的
[WarlockToolsForever](https://github.com/jbedworth/WarlockToolsForever) v1.14.0、
DyresDebuffTracker v1.8.0 与 DyresToolkit v2.18.0，界面与通报已汉化，
并增强了灵魂石/治疗石体验与 Debuff 追踪。

非官方汉化版，与原作者无隶属关系；原版功能与代码版权归 Dyre（John Bedworth），
MIT 许可，各插件目录内附原始 LICENSE。

## 重要变化（1.11.0 起）

持续伤害追踪（含姓名板圆点、伤害预测、智能诅咒）与控制条（宏、恐惧/放逐通报）
已由上游移到 **Dyre's Debuff Tracker**。本包里的 WTF 设置页保留原来的
“持续伤害追踪 / 持续伤害 / 控制”位置；WTF 1.14.0 起直接内嵌 DDT 的设置行
（旧版 Toolkit 下显示为跳转按钮）。因此 **DyresDebuffTracker 现在是必需依赖**。
本仓库里的 DDT 与 DyresToolkit 已完整汉化，并加入了下面列出的增强。

## 安装

1. 下载本仓库（Code → Download ZIP）。
2. 把上面五个文件夹整个放进：
   `World of Warcraft/_forever_/Interface/AddOns/`
3. 进游戏，或输入 `/reload`。插件列表里确认五个插件都已启用。
4. 想要深冬之寒音阶时，再从 CurseForge 安装 Dyre's Sounds 并启用。

`DyresToolkit` 与 `DyresDebuffTracker` 必须保留；另外两个 Dyre 插件只在你想要
对应功能时装。

## 与原版 WarlockToolsForever 的差异

汉化：

- 界面、选项、通告、提示全部中文；专有名词与 Forever 中文客户端一致。
- 宏名（`! Healthstone` 等）、斜杠命令与调试输出保持英文，便于脚本引用。
- 中文文案为魔女口吻，不含插件署名。

增强（`X-WTF-Fork: 1.14.0-fork.1`）：

- **给自己绑灵魂石不再通报**，也不再提示“你的灵魂石已结束”；`/wtf stones`
  仍可查看自己灵魂石的剩余时间。不会再覆盖已给其他玩家的灵魂石记录。
- **灵魂石时限按 Forever 的 2 小时**计算（原版按 30 分钟，会误报）。
- **治疗石/灵魂石按钮即时刷新**：施法成功、背包与冷却变化时立刻更新，
  不再等战斗结束才显示。
- **携带状态一目了然**：有石头时显示实际携带的最高等级图标、金色数量；
  没有时图标去色并叠加红叉、数量红色 `0`、红边框。
- **共享冷却可见**：用掉任意等级的治疗石后，按钮显示冷却转圈与剩余秒数。
- **数量变化闪动**：制造或使用后按钮闪一下，变化一眼可见。
- 战斗中安全按钮仍要等脱战；此时悬停会提示“战斗中：等战斗结束，按钮才会
  用上这块治疗石”。
- **碎片计数器右键裁剪**：一键删除超出上限的灵魂碎片；副本内被游戏拒绝时
  改为离开副本后补删（上游 1.12 功能，已汉化）。
- 1.14.0 上游功能全部保留：设置页“直通”DDT / DBR / Shields Up 的设置行
  （需要 Toolkit 2.17+；插件未装时显示介绍框），石头栏可排成一行或一列
  （需要 Toolkit 2.18），登录欢迎语仍由 DyresToolkit 统一管理。

## DyresDebuffTracker / DyresToolkit 汉化

- 与 WTF 同一套 `Locales.lua` → `DDT.T()` / `ns.T()` 查表方案，
  `GetLocale() == "zhCN"` 时生效；缺词条回落英文。
- DDT 263 条、Toolkit 336 条中文词条，0 缺失；设置页、追踪条、控制条、
  姓名板文案、`/ddt` 命令提示均已覆盖。
- 法术名保持客户端原文（`ClassData` 的 label），在显示时再翻译，
  确保与 Forever 中文客户端的法术名一致。
- 调试输出、引擎字符串、宏名保留英文。

## DDT / Toolkit 增强

- **悬停金色连线**（Toolkit）：鼠标停在追踪行上（锁定时可停在目标/焦点行的
  DoT 图标上）时，金色光点从该行流向对应怪物的姓名板；没有姓名板时指向
  目标/焦点框体。设置：持续伤害页“悬停金色连线”，默认开启。
- **DoT 快结束提醒**（DDT）：最后 3 秒闪烁目标/焦点面板，可伴随
  `RaidWarning.wav` 铃声。设置：持续伤害页“持续伤害快结束时闪烁面板”
  “持续伤害提醒时响铃”，默认开启。
- **放逐快结束提醒**（DDT）：Banish 最后 3 秒闪烁控制条，铃声同上。
  设置：控制页“放逐快结束时闪烁控制条”，默认开启。
- 两项提醒按你的施法时间与技能等级时长推算（Forever 战斗中禁止插件读取
  敌方光环）；被驱散、抵抗或提前解除时可能提前或延后。

以前的 fork 增强里，属于持续伤害追踪与控制条的部分（DoT/放逐快结束提示、
追踪条“目标/焦点”标签、点名字选怪、悬停金线、追踪条本地化）已随功能一起
移到 DyresDebuffTracker，并在本仓库的 DDT 中汉化、补回提醒与金线。

## 上游新功能（WTF 1.14.0 / DDT 1.8.0 / Toolkit 2.18.0）

- **设置页直通**（WTF 1.14.0，需 Toolkit 2.17+）：WTF 设置页里“持续伤害追踪 /
  持续伤害 / 控制 / Shields Up / 冷却提示音 / 触发 / 提醒”各页不再只有跳转
  按钮，而是直接显示所属 Dyre 插件的设置行，读写对方设置；对应插件未安装时
  显示一段介绍框，说明装上后能得到什么。
- **石头栏横排 / 竖排**（WTF 1.14.0 + Toolkit 2.18.0）：石头按钮栏改为 Toolkit
  部件，可拖动、对齐、缩放，并有“排列：横向 / 纵向”设置。
- **DDT 设置分区重构**（DDT 1.8.0）：设置页分成“持续伤害追踪 / 持续伤害 /
  控制 / 减益提示”四块，标题与说明重新精简，条件显示与灰显更准确。
- **“! Curse”宏独立开关**（DDT 1.8.0）：不再跟随控制宏总开关，可在持续伤害页
  单独保留或删除该宏。
- **恶魔印记提示**（DDT 1.8.0，术士）：你的 Demonic Brand 在敌人身上时，其姓名板
  上方显示红色五角星，提示该补了；只有点出该天赋才显示这一节。
- **Toolkit 按键绑定**（2.18.0）：团队标记（骷髅、下一个）、点名 + 信号弹
  （攻击 / 警告 / 协助 / 路上小心）、拉怪倒计时等可直接绑定按键，目标为鼠标
  指向，没有则用当前目标。按键说明随语言显示中文。
- **按钮栏纵向与翻转**（Toolkit 2.18.0）：按钮栏可排成一行或一列，部件上多了
  翻转按钮；设置说明同步精简。
- **威胁 / 坦克工具拆分**（Toolkit 2.18.0）：仇恨警告、坦克工具与挥砍计时已移入
  新的 **Dyre's Threat and Combat Tools**（`/dct`）；本包不含该插件，需要时从
  CurseForge 安装。
- **法师：深冬之寒冰弧与层数音阶**（DDT，需冰霜天赋与 Dyre's Sounds）：冰弧仍在，
  每层点亮一段，可预览、调大小与高度；音阶每层响一声，第 5 层为收束音。
  Forever 客户端禁止战斗日志，音阶走游戏自带施法光环音效（固定音符）。
- `DyresShieldsUp` 1.6.0 与 `DyresBuffReminders` 1.15.0 为上游原样，未做汉化，
  可照常通过 CurseForge 更新。
- 以上新功能均已汉化。

## 更新与兼容

- 客户端：Forever（Interface 16001），简体中文客户端。
- `## Version` 保持与上游一致（1.14.0 / 1.8.0 / 2.18.0），只用
  `X-WTF-Fork` / `X-DDT-Fork` / `X-DTK-Fork` 标记本版本，避免被当成新版本
  反复覆盖。
- WTF 1.14.0 的设置直通与石头栏布局需要 DyresToolkit 2.18.0；旧版 Toolkit
  下会退回原来的跳转按钮与 WTF 自带石头栏。
- **不要用 CurseForge 更新这三个插件**，会覆盖回英文原版。
  上游发新版时，以新上游为准重新合并汉化。
- `DyresShieldsUp`、`DyresBuffReminders` 未改动，可以照常通过 CurseForge 更新；
  但请保持 DBR 1.13.3 或更新（本包为 1.15.0）：1.13.3 起 DBR 把深冬之寒音阶
  交给 DDT，旧版在 Forever 上可能和 DDT 同时响。
- `DyresDebuffTracker`（以及 `DyresShieldsUp`）的 TOC 里把 `DyresSounds`
  列为可选依赖，没有它也能正常加载。
- SavedVariables 不受覆盖影响，配置不会丢失；1.11.0 起旧的追踪/控制设置
  由 DDT 一次性读取，WTF 只原样保留、不修改。深冬之寒音阶设置从 DBR
  读取一次后归 DDT 管理。
